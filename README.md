# 🌤️ SkyCast // Professional Weather Experience

SkyCast is a high-end weather dashboard providing real-time data, 5-day forecasts, and an immersive user experience through dynamic UI changes.

Live Preview: 

## ✨ Premium Features
- **Real-Time Data**: Instant weather updates for any city worldwide.
- **Dynamic Backgrounds**: The app background changes color based on weather conditions (Sunny, Rainy, Cloudy, etc.).
- **5-Day Forecast**: Visualized daily data using OpenWeatherMap's 3-hour interval API.
- **Unit Switching**: Toggle between Celsius (°C) and Fahrenheit (°F) with a smooth UI switch.
- **Geolocation Support**: Get local weather with one click using the browser's Geolocation API.
- **Persistence**: Remembers your last searched city using LocalStorage.
- **Glassmorphic UI**: High-end aesthetic using backdrop blurs and translucent layers.

## 🛠️ Technical Stack
- HTML5, CSS3 (Custom Variables, Flex/Grid)
- Vanilla JavaScript (Async/Await, Fetch API)
- OpenWeatherMap API

## ⚙️ Setup
1. Get a free API Key from [OpenWeatherMap](https://openweathermap.org/).
2. Paste your key into `script.js` at the top: `const API_KEY = 'YOUR_KEY_HERE';`.
3. Open `index.html` in your browser.
